# 桌宠 UI —— 阶段 0 POC 验证说明

> 本阶段目标：验证「透明置顶小窗 + Live2D 会动形象 + 说话张嘴 + 字幕气泡」这条技术路是否走得通。
> **独立脚本，不碰现有 main.py，验证期间零风险，可随时删除。**

## 怎么跑

```bash
python ui_pet/poc.py
```

运行后会弹出一个**透明、无边框、置顶**的小窗，里面是 Live2D 官方示例角色 **Haru**，它会呼吸、眨眼、待机摆动，并循环模拟「说话」：嘴巴张合 + 头顶弹出字幕气泡。

> 这个 POC 里还没有接真实的 DeepSeek 对话和 TTS，是用 `demo_thread` 模拟的说话事件，目的只是验证「窗口 + 形象 + 嘴 + 字幕」能跑通。

## 验证清单（请逐条确认）

| # | 检查项 | 预期 | 通过？ |
|---|---|---|---|
| 1 | 窗口是否透明 | 能看到桌面壁纸，不是白底/黑底方块 | |
| 2 | 是否置顶 | 切到游戏/浏览器，小人仍在最上面 | |
| 3 | 形象是否动 | 有呼吸、眨眼、头发摆动 | |
| 4 | 说话张嘴 | 字幕弹出时，嘴巴在张合 | |
| 5 | 字幕气泡 | 白色气泡出现在头顶，几秒后淡出 | |
| 6 | 能否拖动 | 鼠标按住能拖动窗口位置 | |

## 依赖说明

- **Python 依赖**：新增 `pywebview`（透明窗口框架），需要 `pip install pywebview`
- **前端依赖**：已全部下载到 `ui_pet/vendor/`（pixi.js + Live2D Cubism Core + pixi-live2d-display），**本地加载，不依赖 CDN**
- **模型**：官方示例角色 Haru，已下载到 `ui_pet/models/Haru/`（3MB，免费可商用前先查证）

## 已知风险 / 可能的问题

1. **透明窗口不生效**（最可能翻车的点）：
   - 需要 Windows 自带 **Edge WebView2 Runtime**（Win10/11 默认有）
   - 若窗口出现白底/黑底，说明透明没生效，我会改成「圆角不透明窗」兜底
2. **CDN 兜底**：HTML 里做了「本地文件优先、CDN 兜底」，但本地文件已齐全，正常不会走 CDN
3. **模型版权**：Haru 是 Live2D 官方示例模型，**个人/学习使用免费**，但公开发布（小黑盒）前需要确认授权，正式版建议换成自绘或明确授权的形象
